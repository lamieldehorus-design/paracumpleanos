# Para Cumpleaños

Sitio estático en español para GitHub Pages: frases, ideas, organización y herramientas gratuitas.

## Estructura
- `data/posts.json`: artículos y textos fuente.
- `data/categories.json`: categorías y descripciones.
- `assets/css/site.css`: diseño responsive, sin frameworks.
- `assets/js/site.js`: búsqueda, generador, checklist y calculadora.
- `posts/<slug>/index.html`: páginas estáticas indexables.

## SEO y medición
- Títulos, descripciones, canonical, Open Graph y datos estructurados.
- Páginas de categorías, artículos y enlaces internos.
- Sitemap XML y robots.txt.
- Statcounter integrado en todas las páginas HTML generadas.
- Sin dependencias remotas de JavaScript ni fuentes externas.

El dominio personalizado `paracumpleanos.com` y los archivos de verificación se conservan. GitHub Pages debe estar habilitado en `main`, raíz del repositorio.
