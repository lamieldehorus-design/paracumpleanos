# ParaCumpleanos.com

Sitio estático mobile-first publicado con GitHub Pages y dominio propio.

## Principios
- Fondo blanco y diseño minimalista; amarillo y violeta como acentos discretos.
- Publicaciones creadas a partir de la base de palabras clave, evitando solapamientos de intención.
- Enlaces internos contextuales y útiles entre mensajes, frases, postales y publicaciones.
- Metadatos únicos, canonical, Open Graph, Twitter Cards, datos estructurados, sitemap y robots.
- StatCounter en las páginas públicas.
- IndexNow automatizado mediante la clave pública en `indexnow-key.txt` y el workflow correspondiente.
- Mantener las verificaciones de Google y Bing y el dominio CNAME.

## Publicar
Cada URL se crea como un directorio con `index.html` para que GitHub Pages la sirva sin depender de renderizado del lado del cliente.
